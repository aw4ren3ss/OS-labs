обработке использовать стандартные средства создания потоков операционной системы 
(Windows/Unix). Ограничение максимального количества потоков, работающих в один момент 
времени, должно быть задано ключом 

Отсортировать массив целых чисел при помощи TimSort.

**Компиляция и запуск**

```bash
cc -pthread -o threads_lab threads_lab.c
./threads_lab -s <arrSize> -t <n_threads> -a <1/0>
```
